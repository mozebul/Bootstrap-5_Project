# FoodCollections — Complete Multi-Page Bootstrap Project

## Pages
- `index.html` — Home
- `collections.html` — Collections
- `restaurants.html` — Restaurant listing, search and filters
- `details.html` — Restaurant details
- `signin.html` — Sign-in form
- `add-restaurant.html` — Add restaurant form
- `contact.html` — Contact form
- `css/style.css` — Shared styling
- `js/script.js` — Search/filter/form/details JavaScript

## Technology
HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons and JavaScript.

## Run
1. Extract the ZIP.
2. Open the `FoodCollections` folder in VS Code.
3. Open `index.html` with Live Server.
4. Internet is needed for Bootstrap CDN and Unsplash images.

## Features
Responsive navbar, separate page interfaces, restaurant cards, search, category filter, price filter, dynamic details page using `?id=`, forms with browser validation and demo success messages.

This is a front-end project. Forms do not connect to a real database/backend.
